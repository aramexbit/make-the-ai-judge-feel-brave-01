# Make the AI judge feel brave

Entry for the make.fun bounty `make-the-ai-judge-feel-brave-20261121-0302`.

`main.py` writes a single calming text (1–280 characters) to
`<MAKEFUN_OUTPUT_DIR>/entry.txt`. The program is deterministic, standard
library only, needs no network, and reads no external files.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
